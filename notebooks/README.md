# Laboratorët 02–12 — Simulim dhe Metoda Numerike

Kjo paketë vijon drejtpërdrejt leksionet e kursit dhe nuk përfshin Laboratorin 01. Për çdo laborator jepen dy versione:

- `Instruktori/`: notebook i zgjidhur, me zbatime të plota në Python dhe MATLAB/Octave;
- `Studenti/`: notebook i udhëzuar me pjesë `TODO`, i destinuar për punë të pavarur.

Në çdo notebook, Python është në gjysmën e parë dhe MATLAB/Octave në gjysmën e dytë. Qelizat MATLAB/Octave ruhen si qeliza `raw`, në mënyrë që pjesa Python të ekzekutohet pa gabime me kernelin standard. Ato mund të kopjohen në MATLAB/Octave ose të shndërrohen në qeliza kodi me kernelin përkatës.

## Kërkesat për Python

Python 3.10+, NumPy, Matplotlib dhe SciPy. Laboratori 08 përdor vetëm NumPy për shpërndarjen normale shumëpërmasore; pjesa MATLAB e tij përdor `mvnrnd`, e cila në Octave kërkon paketën `statistics`.

## Rendi i punës

1. Lexoni kapitullin përkatës të leksioneve.
2. Zgjidhni Python ose MATLAB/Octave.
3. Ekzekutoni rastin bazë dhe kontrollin e verifikimit.
4. Kryeni studimin parametrik.
5. Raportoni figurat, tabelat, gabimin dhe interpretimin fizik.
